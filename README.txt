IFEABUNIKE MMACHUKWU FAVOUR'S EDUCATIONAL PORTFOLIO

FILES
- index.html: website content
- style.css: layout, colours and responsive styling
- script.js: mobile navigation interaction
- assets/beauty-at-desk.jpg: uploaded desk photograph used in the hero section
- assets/beauty-portrait.jpg: uploaded outdoor portrait used in the About section

HOW TO USE
1. Extract the ZIP file.
2. Open the folder in your code editor (for example, VSCodroid).
3. Open index.html in Chrome to preview the website.
4. Replace the sample email address with your preferred contact email.
5. Edit any project descriptions, skills and details as your portfolio develops.

The website is responsive and includes About, Education, Skills, Projects, Goals and Contact sections.
The two personal photographs are stored locally in the assets folder, so they do not depend on an external image website.
Google Fonts and the sample project photos still use online resources.
